Edemy is a full-stack web application developed as an end-of-studies project. The platform is designed to provide users with an interactive and modern educational experience.

The project includes:

A frontend client application
A backend server API
A recommendation system built with Flask

🚀 Features
🔐 User Authentication
📚 Course Management
👨‍🏫 Instructor & Student Interfaces
❤️ Course Recommendations
🔎 Search & Filtering
📱 Responsive UI
📊 Dashboard & Analytics

🛠️ Technologies Used
Frontend
React.js
Bootstrap / CSS
Axios
Backend
Node.js
Express.js
MySQL
Recommendation System
Flask
Python
Machine Learning Algorithms

▶️ Run the Frontend
cd client
npm install
npm start

▶️ Run the Backend
cd server
npm install
npm start
▶️ Run Flask Recommendation System
cd flask-recommendation
python app.py
